# Morya Door & Decors

A responsive static website for **Morya Door & Decors**.

## Structure

- `index.html` — home page with Leaflet map
- `doors.html` — door categories
- `decor.html` — decor categories
- `single-door.html`
- `double-door.html`
- `security-door.html`
- `fancy-door.html`
- `customized-door.html`
- `windows.html`
- `chairs.html`
- `css/style.css` — isolated styling
- `js/main.js` — isolated JavaScript
- `images/` — image placeholders referenced by the HTML

## Images

No actual image files are included. The pages intentionally reference paths such as:

`./images/double.jpeg`

Add your real images later using the same filenames.

## Run

Open `index.html` in a browser. Internet access is required for the Leaflet/OpenStreetMap map because Leaflet CSS/JS and map tiles are loaded from their public CDNs.
